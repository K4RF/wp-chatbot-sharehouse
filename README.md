# 공간나인 쉐어하우스 AI 챗봇 플러그인

WordPress용 쉐어하우스 입주 문의 AI 챗봇 플러그인입니다.

## ✨ 주요 기능

-   **AI 챗봇 응대**: OpenAI의 `gpt-4o-mini` 모델을 사용하여 고객 문의에 24시간 자동으로 응답합니다.
-   **실시간 공실 정보 연동 (RAG)**: Notion 데이터베이스와 연동하여 최신 공실 정보를 검색하고 고객에게 정확한 정보를 안내합니다.
-   **관리자 채팅 기능**: 관리자가 실시간으로 고객과 직접 채팅할 수 있으며, 필요시 AI 자동 응답을 중지하거나 재개할 수 있습니다.
-   **간편한 설치**: 숏코드 `[gn_chatbot_page]`를 페이지에 추가하는 것만으로 챗봇을 쉽게 삽입할 수 있습니다.
-   **대화 기록 저장**: 모든 상담 내용은 데이터베이스에 저장되어 관리자 페이지에서 확인할 수 있습니다.

## 🔧 설치 방법

1.  **플러그인 업로드**:
    -   다운로드한 플러그인 폴더(`wp-chatbot`)를 WordPress 사이트의 `/wp-content/plugins/` 디렉토리에 업로드합니다.

2.  **API 키 설정**:
    -   `wp-chatbot` 폴더 안에 `gnbot-config.php` 파일을 생성하고 아래 내용을 복사하여 붙여넣습니다.
    -   `GNBOT_OPENAI_KEY`, `GNBOT_NOTION_KEY`, `GNBOT_DATABASE_ID`에 발급받은 실제 키 값을 입력합니다.

3.  **플러그인 활성화**:
    -   WordPress 관리자 페이지의 '플러그인' 메뉴로 이동하여 '공간나인 AI 매니저'를 찾아 활성화합니다.

## 🚀 사용 방법

1.  WordPress 관리자 페이지에서 새 페이지를 생성하거나 기존 페이지를 편집합니다.
2.  챗봇을 표시하고 싶은 위치에 아래의 숏코드를 삽입합니다.

    ```
    [gn_chatbot_page]
    ```

3.  페이지를 저장하고 확인하면 해당 위치에 챗봇이 나타납니다.
